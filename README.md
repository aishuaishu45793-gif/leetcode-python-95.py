Download Python: https://www.python.org/downloads/

## ▶️ How to Run the Programs

### Step 1: Open the Project

Open the required project folder in Visual Studio Code.

### Step 2: Open the Terminal

Select **Terminal → New Terminal**.

### Step 3: Run the Python File

Use the following command, replacing `main.py` with your actual Python filename:

```bash
python main.py
```

On Windows, you can also try:

```powershell
py main.py
```

### Step 4: Check the Output

View the program output in the VS Code terminal. You can change the input values and run the program again to understand how it works.
